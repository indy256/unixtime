What is a Unix timestamp?

A Unix timestamp counts seconds since January 1, 1970 at 00:00:00 UTC, excluding leap seconds. It identifies the same instant everywhere, making it useful for storing and comparing dates.

What about the year 2038?

On January 19, 2038, timestamps exceed the largest signed 32-bit integer. Systems using signed 64-bit timestamps can represent dates far beyond that limit.
